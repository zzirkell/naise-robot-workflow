# NAiSE Robot Workflow

Node-RED workflow for testing REST-based robot order handling.

## Run

Requirements: Docker Desktop + Docker Compose.

Clone the repository and start:

    git clone <repository-url>
    cd naise-robot-workflow
    docker compose up -d

Open:

Node-RED: http://localhost:1880  
Dashboard: http://localhost:1880/ui

Stop:

    docker compose down
